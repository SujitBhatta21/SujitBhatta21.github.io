An interactive visualiser built with Pygame that lets users construct a grid, place start/end points, add obstacles, and watch the A* algorithm find the shortest path in real time.

---

## Features

- Draw obstacles, set start and end nodes on a resizable grid
- Step-by-step visual of A* open/closed set expansion
- Multiple screens: intro, grid-size input, play, endgame
- g-cost + h-cost heuristic evaluation displayed visually
